# Nitro Moto

**Racing / Physics** — a 100% web HTML5 game.

Physics-based stunt motorbike racing across deadly obstacle tracks. Lean, flip and land to beat the clock.

## How to play
Arrow keys / WASD to accelerate, brake and lean; perform flips for time bonus.
